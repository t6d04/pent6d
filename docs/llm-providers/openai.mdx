## Setup

```bash
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="sk-..."
```

## Native web search

OpenAI models can research CVEs, advisories, and public PoCs through the
hosted Responses API web-search tool, without an Exa or Perplexity key:

```bash
export STRIX_WEB_SEARCH_PROVIDER="native"
# Optional: low, medium (default), or high
export STRIX_NATIVE_WEB_SEARCH_CONTEXT_SIZE="medium"
```

`auto` selects native search for this direct OpenAI setup. Native search does
not work through a custom `LLM_API_BASE` or the Chat Completions API; select
Exa or Perplexity for those routes.

## Available Models

See [OpenAI Models Documentation](https://platform.openai.com/docs/models) for the full list of available models.

## Get API Key

1. Go to [platform.openai.com](https://platform.openai.com)
2. Navigate to API Keys
3. Create a new secret key

## Custom Base URL

For OpenAI-compatible APIs:

```bash
export STRIX_LLM="openai/gpt-5.4"
export LLM_API_KEY="your-key"
export LLM_API_BASE="https://your-proxy.com/v1"
```
